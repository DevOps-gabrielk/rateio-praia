# Rateio da praia

Página única, sem servidor e sem login: abre no navegador e guarda tudo no
próprio aparelho de quem abriu.

Cada pessoa marca os itens que foram dela, o que ninguém marcar fica em
destaque, e o topo mostra quem paga quanto pra quem. Para juntar as
marcações de todo mundo, cada um copia o próprio link e o organizador cola
na tela — o merge só mexe no nome de quem mandou.
